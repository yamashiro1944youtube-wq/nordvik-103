# ノルドヴィーク戦記 ―103高地攻防戦―

第五次ノルドヴィーク攻勢（1945年10月7日～13日）を題材にした、ヘクス戦術級戦略ゲームです。
単一の `index.html` をブラウザで開くだけで遊べます（ネット接続不要）。

## 概要

- 126高地を奪取したネスメルソン北部軍集団が、北方の103高地を攻略にかかる
- 守備側は第14・第15婦女子戦闘師団の残存部隊を中心とするリクショール／ノルドヴィーク海軍政府軍
- 103高地の主陣地は北側の反斜面にあり、126高地からの砲兵観測・準備砲撃が効きにくい
- 開始時にプレイ陣営を選択（ネスメルソン＝攻勢側／リクショール＝守備側）。相手陣営はAIが操作します

## ルール

- **14ターン＝7日間**。昼ターンと夜ターンを1日として進みます
- 7日（ワンセット）終了時に判定と補給フェイズがあり、長期戦として継続できます
- 地形により防御・移動・砲撃にバフ／デバフ（反斜面、塹壕・岩盤壕、森林、岩場、街道、トンネル網など）
- 戦闘は射撃／白兵戦／対戦車肉薄攻撃
  - 白兵戦は地形防御を半減させる代わり、仕掛けた部隊はそのターン無防備になり射撃に弱い
  - 肉薄攻撃は犠牲が大きい代わり、成功すると戦車を「足止め＋盲目」にできる
  - 狙撃班は戦車長や観測装置を狙い、戦車を盲目化できる
- 夜ターンには **夜襲ボーナス**：白兵戦・近接戦闘・肉薄攻撃が強化されます
- 歴史イベント：大準備砲撃（10月7日）、白兵戦激化（10月8～9日）、戦車投入解禁（10月10日）
- 守備側は軽巡による艦砲支援を1日2回まで使用可能。対戦車砲の集中配置でパックフロントが成立します

## 音響

- BGM：ネスメルソン陣営は「抜刀隊」、リクショール側は「カチューシャ」（旋律のシンセ演奏、上部ボタンでBGM／SE個別にオン・オフ可能）
- SE：射撃＝銃声、白兵戦＝剣戟音、砲兵・艦砲＝砲撃音、肉薄攻撃＝突撃ラッパ

## 勝敗

- ネスメルソン勝利：山頂＋反斜面主陣地＋トンネル入口2か所以上を制圧
- 守備側勝利：10月13日終了時点で反斜面主陣地を保持
- 山頂のみ確保は史実通り「攻勢停止」。損害率によりランクS～Dで評価されます
